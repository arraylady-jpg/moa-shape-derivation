# Contributed Hardware Shapes

Community-contributed GPU architectural measurements, in the format
produced by `moa-shape contribute` (see `../CONTRIBUTING.md`).

Seeded initially with this project's own three NVIDIA GPUs (V100,
A100, H100), already validated by hand against real-hardware kernel
results in this project's other publications. Contributions of
genuinely new hardware -- any AMD GPU, any NVIDIA generation not
listed here, anything else -- are the most useful addition anyone
outside the core project can make.
